4. Decide which exams to read comments for
5. Click the ones with most comments (many suggestions from others)
6. Fast! Easy! Efficient!

PERFORMANCE - No Blocking:
================================================================================

✅ Asynchronous loading:
   - loadStats() loads like/dislike counts
   - loadCommentCount() loads comments in parallel
   - Both run without blocking UI rendering
   - Comments show loading spinner while fetching

✅ Error handling:
   - If API fails, commentCount stays at 0
   - No crash, no broken UI
   - User can still vote and comment normally
